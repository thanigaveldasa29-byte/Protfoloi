## 🌐 Free 1-Click Deployment Options

### Option A: GitHub Pages
1. Create a new GitHub repository named `thanigavel-portfolio`.
2. Push this folder's contents:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Thanigavel D cybersecurity portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/thanigavel-portfolio.git
   git push -u origin main
   ```
3. In GitHub repo settings, go to **Pages** > Select Branch `main` > Save. Your portfolio is live!

### Option B: Vercel or Netlify
- Drag and drop this folder directly into [Vercel](https://vercel.com) or [Netlify](https://netlify.com) for instantaneous deployment with SSL.
